🚀 Download and Setup on Windows

Getting started takes only a few minutes. Follow the steps below in order and you will have everything in place.

  1. Visit the download page. Visit this link to download the application: https://github.com/imbani/VLSIT_ASIC_SOC_AI_SKILLS
  2. Save the files to your PC. Use the green Code button on the page, then choose the option that downloads everything as a single compressed folder. Windows will place it in your Downloads folder by default.
  3. Unpack the folder. Right-click the downloaded folder and choose Extract All. Pick a simple location such as C:\VLSIT_Skills so the path stays short and easy to find.
  4. Look inside. Open the extracted folder in File Explorer. You will see organized files and instruction documents that describe each skill.
  5. Open the documents. Any plain text or Markdown file can be opened with Notepad, which is already installed on Windows. Right-click a file, choose Open with, then Notepad.
  6. Connect your AI tool. Point your assistant at the extracted folder, or copy the text of a skill file into your chat as context. The assistant will then follow the guidance it finds there.

Tip: Keep the extracted folder in one place and do not rename the internal files. Assistants and scripts often look for exact file names, and renaming can break that link.

The package is lightweight. Most modern Windows laptops and desktops handle it without any changes.

  • A current version of Microsoft Edge, Google Chrome or Firefox for opening the download page.
  • About 200 MB of free disk space for the files and any notes you create.

📖 A Simple First Session

If you have never worked with chip design files before, this short walkthrough gives you a comfortable starting point.

  1. Open the extracted folder and find the general overview document near the top of the list.
  2. Read the first two or three pages slowly. The terms will feel unfamiliar at first, and that is normal.
  3. Pick one small topic that interests you, such as how a design block is described in text form.
  4. Open your AI assistant and paste that section in, then ask a plain question like "explain this to a beginner".
  5. Write down the answers you find useful in a separate notes file so you build your own summary over time.
  6. Repeat with the next topic. Small sessions of twenty minutes work better than long ones.

🔧 If Something Does Not Work

  • The file will not open: right-click it, choose Open with, and select Notepad from the list.
  • The folder looks empty: the extraction step probably did not finish. Run Extract All again and wait for it to complete.
  • Text looks like one long paragraph: widen the Notepad window, or turn on word wrap from the Format menu.
  • Your browser blocks the download: look for a small arrow or warning icon in the address bar and allow the file for this site.
  • Paths feel too long: move the folder closer to the drive root, for example C:\VLSIT_Skills.
  • You lost track of where things are: press the Windows key, type the folder name, and the search results will show its location.
